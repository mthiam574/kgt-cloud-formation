# A propos — Moustapha THIAM
Admin sys Linux en formation DevOps Cloud. Ce projet documente une montee
en competences structuree sur AWS, GCP et Azure.
## Profil technique
Base : Administration systeme Linux (Debian), shell scripting, reseaux TCP/IP
En cours d'acquisition : DevOps Cloud, IaC, conteneurs, CI/CD, observabilite, Kubernetes
Environnement de travail : Debian Linux, VS Code, Git/GitHub, terminal
## Stack a l'issue de cette formation
Infrastructure cloud : AWS (IAM, ECR, ECS Fargate, EKS, CloudWatch), GCP (Artifact Registry,
Cloud Run, GKE, Cloud Monitoring), Azure (ACR, ACI, AKS, Azure Monitor)
Outillage DevOps : Docker, Terraform multi-cloud, GitHub Actions CI/CD, kubectl
Observabilite : CloudWatch, Cloud Monitoring, Azure Monitor — logs, metriques, alertes
Orchestration : Kubernetes — GKE (GCP), EKS (AWS), AKS (Azure)
## Services pratiques par categorie
| Categorie | AWS | GCP | Azure |
|---|---|---|---|
| **Phase 01 — Fondations** | IAM, CLI, budget | gcloud, budget | az, budget |
| **Phase 02 — Conteneurs** | ECR, ECS Fargate | Artifact Registry, Cloud Run | ACR, ACI |
| **Phase 03 — IaC et CI/CD** | Terraform, GitHub Actions | Terraform, GitHub Actions ⏳ | Terraform, GitHub Actions |
| **Phase 04 — Observabilite** | CloudWatch | Cloud Monitoring | Azure Monitor |
| **Phase 05 — Kubernetes** | EKS | GKE | AKS |
## Demarche
Formation construite de maniere progressive : chaque phase valide les acquis de
la precedente avant d'avancer. Les erreurs rencontrees sont documentees — elles
font partie de l'apprentissage.
